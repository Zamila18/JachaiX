# Copilot Training Plan for JachaiX

## 1) New Developer Onboarding Checklist
- [ ] Enable Copilot in IDE + GitHub account
- [ ] Read `docs/COPILOT_GUIDE.md`
- [ ] Read workflow and best-practice docs
- [ ] Configure IDE settings from this repo
- [ ] Complete 3 practice exercises below
- [ ] Open 1 PR using Copilot-generated summary + review

## 2) Recommended Video Learning
- GitHub Copilot docs and tutorials: https://docs.github.com/en/copilot
- GitHub YouTube channel (Copilot playlists): https://www.youtube.com/github

## 3) Practice Exercises (JachaiX-specific)
1. **Trust Score Helper (Python):** implement + tests + docstring.
2. **Bangla Normalization Utility (TS/Python):** handle mixed input + edge cases.
3. **Laravel Endpoint Hardening:** add validation, error mapping, and tests.

## 4) Common Mistakes and How to Avoid
- Blindly accepting generated code → always run tests and review.
- Missing Bangladesh context → include local examples in prompts.
- Ignoring privacy → mask sensitive data in prompts/logs.
- Skipping explainability → require evidence and confidence rationale.

## 5) Suggested Enablement Cadence
- Weekly: review Copilot usage pain points.
- Bi-weekly: update prompts/spaces.
- Monthly: refresh this documentation with new Copilot capabilities.
