# Additional IDE Copilot Settings Recommendations

## Visual Studio (non-Code)
- Enable GitHub Copilot and Copilot Chat extensions.
- Turn on inline suggestions and solution-wide context where available.

## Neovim/CLI workflows
- Use GitHub Copilot plugin with explicit keybindings for accept/next/previous suggestion.
- Keep project instructions in `.github/copilot-instructions.md` open while prompting.

## Eclipse / other IDEs
- Use official GitHub Copilot plugin if available.
- Mirror the same behavior: inline suggestions, chat panel, and project instruction awareness.
