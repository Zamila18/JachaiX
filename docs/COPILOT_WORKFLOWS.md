# Copilot Workflows for JachaiX

## Workflow 1: Developing a New Fact-Checking Feature
1. Enable **Copilot Memory** for context retention.
2. Use **Copilot Chat in IDE** to discuss architecture.
3. Implement with inline suggestions.
4. Use **Copilot Web Search** for latest fact-checking methods.
5. Generate unit tests with Copilot.
6. Use Copilot-generated commit messages.
7. Enable automatic Copilot review on PR.

**Prompt starter:**
> "Design a modular fact-check pipeline for Bangla claims with confidence explanation and source citations."

---

## Workflow 2: Debugging Multimodal Processing
1. Use Copilot Chat to analyze stack traces/logs.
2. Use **Model Native Search** to locate relevant code paths.
3. Ask for similar robust handling patterns.
4. Use **Copilot Cloud Agent** for multi-step fix + validation suggestions.
5. Document resolution pattern in a **Copilot Space**.

**Prompt starter:**
> "Trace this image-processing failure and suggest safe fallback behavior with tests."

---

## Workflow 3: Bangla Language Processing
1. Use Web Search for current Bangla NLP libraries.
2. Use Chat in IDE for implementation strategy.
3. Validate ideas in Jupyter notebooks.
4. Generate tests for Bangla edge cases.
5. Record reusable rules/edge cases in Copilot Memory.

**Prompt starter:**
> "বাংলা টেক্সট normalization (NFC/NFKC, punctuation, সংখ্যা) এর জন্য utility + tests তৈরি করো।"

---

## Workflow 4: PR Review and Release Readiness
1. Request Copilot summary of PR impact.
2. Enable automatic Copilot code review.
3. Ask Copilot to list risk hotspots (security/privacy/performance).
4. Validate fixes and regenerate commit message.
5. Merge only after human + Copilot review alignment.
